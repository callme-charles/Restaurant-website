# Charles Kitchen 🍲

A modern, responsive restaurant web application built from scratch to showcase authentic Nigerian cuisine, local pricing in Naira, and clean frontend development practices.

## Live Demo
Check out the live site here: [Charles Kitchen Live Link](https://callme-charles.github.io/Restaurant-website/)

## Features
- **Authentic Naija Menu:** Features popular local delicacies including Party Jollof & Turkey, Ofada Rice & Ayamase, Pounded Yam & Egusi, Suya, and Chapman.
- **Local Pricing:** Real-world menu pricing formatted in Nigerian Naira (₦).
- **Responsive UI:** Styled with a clean, dark-themed layout built using modern CSS Grid and Flexbox.
- **Interactive Elements:** Powered by vanilla ES6 JavaScript DOM manipulation.

## Tech Stack
- **HTML5:** Semantic and structured markup.
- **CSS3:** Custom styling and responsive design.
- **JavaScript:** Event-driven UI interactions.
- **Deployment:** Hosted live on GitHub Pages.
